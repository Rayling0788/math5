# CUMCM 2026 Official Format Contract

Use this contract for 2026 and later CUMCM papers unless a newer official rule is supplied. For an earlier contest year, use it only when the user explicitly requests this revision. Source: `https://univs-news-1256833609.file.myqcloud.com/123/upload/resources/file/10357946.pdf`, titled `全国大学生数学建模竞赛论文格式规范（2026 年修订稿）`, accessed 2026-07-27.

## Authority

The official format overrides bundled templates, reference-paper styling, and local habits. It controls submission structure, anonymity, page boundaries, appendices, and electronic-package limits; it does not dictate modeling content, font family, line spacing, or color beyond local division rules.

## Paper Contract

- Use white A4 paper with every margin at least 2.5 cm.
- The electronic paper excludes the commitment and numbering sheets. Its first page is the abstract page.
- Put title, Chinese abstract, and keywords on the abstract page. No English abstract is required. Keep this page to one page in principle.
- Start Arabic page numbering at `1` on the abstract page, centered in the footer, and continue without reset.
- Begin the main text on the next page. Do not include a table of contents.
- Keep the main text at or below 30 pages. Appendices follow the main text and have no stated page limit.
- Keep the submission anonymous: abstract, main text, appendices, and support files must not reveal team members, school, or contest region.
- Cite every external or public source in the text and reference list.

## Appendix And Support Contract

- Put a support-material file list in the paper appendix.
- Include all complete runnable source programs and interactive software commands used for modeling in the paper appendix. A short excerpt alone is insufficient.
- Submit one paper file in PDF or Word format; PDF is preferred. The paper file must not exceed 20 MB and must not be wrapped in another archive.
- Submit support materials as one RAR or ZIP archive not exceeding 20 MB. Include runnable source code, independently collected external data, and large intermediate result tables needed to support claims. Original contest attachments need not be duplicated.
- Keep the electronic paper consistent with the printed paper, including appendices. Keep support files consistent with the paper and its reported results.
- Do not put commitment or numbering sheets in the electronic paper or support archive.

## Incremental Checks

Before writing, remove template pages that violate the contract. Before final delivery, verify the first page visually, search source and PDF text for a table of contents, confirm page numbering, identify the main-text/appendix boundary, count main-text pages, inspect anonymity, list every support file in the appendix, confirm every listed source exists, test the documented entry command, and check both file sizes.

Treat a missing full source appendix, a table of contents, an unnumbered abstract page, a main text over 30 pages, identity leakage, a paper/support mismatch, or either file over 20 MB as blocking.
