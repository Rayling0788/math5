## 获取指定版本

```bash
git clone --branch version/v7 https://github.com/Rayling0788/math5.git
```

也可以克隆仓库后签出固定标签：

```bash
git checkout v7.0.0
```

Codex 技能入口位于仓库根目录的 `SKILL.md`。
